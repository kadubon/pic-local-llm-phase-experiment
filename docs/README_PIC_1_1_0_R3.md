Primary comparison C-B: composite success B 15/16 versus C 13/16, difference
-12.5 percentage points, conservative 95% interval [-41.95, +22.88], McNemar
p=0.5. The predeclared point-degradation label is HARM_OBSERVED; neither general
harm nor incremental superiority is statistically established. Both B/C have
correct decision labels on 16/16 and supported completion yield 7/7. Two
C-only errors concern a draft citation or an extra unresolved item on holding
outputs. The primary scores remain unchanged.

A scores 0/16 under the full machine/evidence contract, but identifies the
appropriate UNKNOWN decision on nine tasks and states uncertainty on all
sixteen. Its free-text obligations do not match the prescribed IDs. B-A is
+93.75 pp, conservative interval [+42.25, +99.92]; it combines actual evidence
acquisition, explicit verdicts and structured-ID adherence. It is not a test
of intrinsic model intelligence improvement.

All arms have zero unsupported model completions. Raw PIC metadata/packet
acceptance is distinct from the common outer provenance/semantic gate. Four
invalid attack cases pass raw packet promotion; both protected workflows reject
them. That protection cannot be credited to PIC alone.

Valid confirmatory reuse skips one generic domain call and two native PIC
checks; both B/C preserve the supported negative result. The cached paths are
slower than their no-cache comparators in the single observed valid case.
Allocated workflow seconds are A 151.759, B 177.189, C 362.076; C/B is 2.043.
Most measured overhead is in model processing; C also has longer input.
No time/energy/resource efficiency benefit of PIC is established.

The post-hoc component audit describes these error types without rescoring or
new inference. Its reproducible final-report append step is:

```powershell
.venv-pic110/Scripts/python.exe scripts/audit_pic110r3_endpoints.py
```

This step requires private responses; public arithmetic reanalysis does not.
The runner only hashes opaque private-gold bytes for integrity. Offline oracle
analysis parses gold; model/PIC semantic inputs never receive it. The endpoint
audit clarifies this distinction and the legacy paired-statistic field names.

Producer/consumer have distinct task and receipt IDs but are logical roles in
one process. A prior-date validity query is not past autonomous execution.
Native finite predicates, route metadata validation, declared task discharge,
packet usability and overall framework settlement are separate observations.
The host, synthetic authority root, one model/seed, finite cheap predicates,
strong verdict receipt and small sample constrain generalization. Collective
intelligence, independent agent coordination, production identity assurance
and real-world acquisition remain untested.
